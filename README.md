# Дневники и назначения

Приложение для ведения дневников истории болезни и листов назначений. Разработка ведётся в ветке `develop`.

На первом этапе доступны два раздела: «Дневники» (один книжный лист A4) и «Назначения» (два альбомных листа A4). Бланки пустые, с заголовками и кнопкой печати. Поля для заполнения и сохранение документов будут добавлены после согласования структуры бланков.

Проект создан на основе `blood`: исходные компоненты форм, печати, локальной базы и работы без сети сохранены в коде для дальнейшего использования. Прежние формы не доступны через интерфейс приложения. Приложение работает по отдельному адресу и не открывает базу данных `blood`.

```bash
npm ci
npm run dev
npm run check
```
